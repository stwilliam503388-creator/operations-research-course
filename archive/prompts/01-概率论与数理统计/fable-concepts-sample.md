## 课程：`01-概率论与数理统计/`

### 章节：`01-prob.md`

#### 概念 1：连续随机变量的概率密度不是概率

**建议融入位置**：`## 1.3 随机变量与分布` 中 “离散 vs 连续” 表格之后，紧接 “PDF 的值可以大于 1”。

**为什么选这个概念**：

这是概率入门里最容易被误读的概念之一。读者常把 PDF 在某点的高度当成概率，从而困惑“为什么密度可以大于 1”。如果这里讲清楚，后面理解正态分布、指数分布、QQ 图和安全库存都会更稳。

**寓言故事标题**：窄巷里的灯

**寓言故事**：

城里有一条很窄的布市，夜里靠油灯照明。市政官想知道每一段街有多亮，于是让灯匠把灯挂得更密。宽街上，灯隔得远，光摊得开；窄巷里，灯被挤在一起，某一小段看起来亮得吓人。

新来的书记拿着尺子巡街，看到窄巷中间那一尺特别亮，便说：“这里的亮度已经超过一整条街，账一定错了。”灯匠摇头，把书记带到城楼上看。远远望去，窄巷确实有一处亮得尖锐，但它只占很短一段；宽街的光不那么高，却铺得很长。若问“这一点有多亮”，窄巷可以很高；若问“这一整段总共有多少光”，还得看亮度乘上长度。

书记这才明白，他错把“某一点的浓淡”当成“某一段的总量”。故事快结束时，这个道理才露出原形：连续世界里，我们不能问一个精确点有多少概率，而要问一段区间下的面积有多少。那个可能很高的曲线高度，讲的不是概率，而是概率密度。

**概念解释**：

- 一句话人话：PDF 像“概率的浓淡”，某一点的高度不是概率，一段区间下面积才是概率。
- 严格一点说：连续随机变量满足 `P(a <= X <= b) = ∫[a,b] f(x) dx`，而单点概率通常为 0；`f(x)` 可以大于 1，只要总积分为 1。
- 容易误解：`f(3)=2` 不表示 `X=3` 的概率是 2，也不表示概率超过 100%。
- 在本课程案例中怎么用：正态、指数、对数正态等连续分布都用 PDF 描述形状，用 CDF 或积分计算概率。
- 现实中什么时候会失效：如果数据本身是计数、订单数、点击次数等离散变量，用 PMF 或离散分布更自然，不应硬套连续密度。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 窄巷中某一点很亮 | PDF 在某点取值很高 | 高度可以大于 1，但不是概率 |
| 一段街的总光量 | 区间概率 | 要把密度在区间上累积 |
| 宽街光低但铺得长 | 低密度但区间宽 | 面积仍可能很大 |
| 书记误判账错 | 把密度误作概率 | 常见初学误解 |
| 城楼上看整段街 | 从点值转向面积 | 理解连续概率要看积分 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：如果某个 PDF 在 `x=0.2` 的高度是 2，这是不是表示概率是 200%？

不是。PDF 的高度像“概率浓度”，真正的概率是一段区间下面积。连续随机变量里，单点通常没有概率质量，只有区间才有概率。
```

**边界与风险提醒**：

这个故事可能让读者以为 PDF 只是可视化工具。正文应补一句：PDF 是严格的数学对象，必须非负且总积分为 1。

### 章节：`02-statistics.md`

#### 概念 1：置信区间的覆盖率

**建议融入位置**：`## 2.2 置信区间：给估计一个范围` 中 “置信区间的解读” 之前。

**为什么选这个概念**：

章节已明确指出“真实均值有 95% 概率落在区间内”是错的。覆盖率是频率学派统计推断的关键直觉，适合用寓言纠正“真值随机跳动”的误解。

**寓言故事标题**：渔夫的百张网

**寓言故事**：

湖里有一条传说中的白鱼，位置固定在湖心某处，但湖面雾很大，谁也看不见。渔夫们每天天亮前撒一张网，网的位置由当天的风、水流和船的晃动决定。老渔夫说：“我的网法若重复一百天，大约九十五张网会罩住那条鱼。”

年轻人听后很兴奋。第一天，他撒下一张网，马上对旁人说：“这条鱼有九成五的机会在我的网里。”老渔夫摇头：“鱼没有在湖里乱跳。它要么在网里，要么不在。会变的是你的网。”

年轻人不服，连续撒了一百张网。他发现有些网偏左，有些偏右，有些太窄，有些太宽，但老渔夫的方法确实让大多数网罩住湖心附近。到这时他才明白，老渔夫说的不是某一张网里鱼的概率，而是一种撒网方法长期表现如何。

故事快结束时，答案才显出来：这里讲的不是捕鱼，而是置信区间。真值像那条位置固定的鱼；每次抽样生成的区间像一张随机的网；“95%”说的是这种造网方法反复使用时，大约 95% 的区间会覆盖真值。

**概念解释**：

- 一句话人话：置信区间的 95% 不是说这次真值有 95% 概率在里面，而是说这种方法长期有 95% 的覆盖能力。
- 严格一点说：若按同一程序反复抽样并构造 95% 置信区间，则这些随机区间中约 95% 会包含固定但未知的参数。
- 容易误解：构造出具体区间后，频率学派语境下参数不是随机变量，不能说“它有 95% 概率落入该区间”。
- 在本课程案例中怎么用：A/B 测试、均值估计、效应量报告都应同时给点估计和区间估计。
- 现实中什么时候会失效：如果抽样有偏、样本不独立、方差估计错误，标称 95% 的区间未必真有 95% 覆盖率。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 固定白鱼 | 固定但未知的真参数 | 参数不随抽样随机变化 |
| 每天撒出的网 | 每次抽样得到的置信区间 | 区间随样本变化 |
| 一百张网约九十五张罩住鱼 | 95% 覆盖率 | 长期重复程序的性质 |
| 年轻人误读第一张网 | 错把覆盖率当后验概率 | 常见解释错误 |
| 风、水流、船晃动 | 抽样随机性 | 样本不同导致区间不同 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：一旦你算出了 `[49, 55]` 这个具体区间，随机的是区间，还是那个真实均值？

频率学派的回答是：真实均值固定但未知，随机的是抽样得到的区间。95% 置信水平描述的是“造区间的方法”长期有多可靠。
```

**边界与风险提醒**：

这个故事可能让读者误以为置信区间与贝叶斯可信区间只是说法不同。正文应补一句：若要表达“参数在区间内的后验概率”，需要贝叶斯可信区间，而不是频率学派置信区间。

### 章节：`03-case-distributions.md`

#### 概念 1：QQ 图的尾部诊断

**建议融入位置**：`### 方法1：QQ 图（分位数-分位数图）` 之后，作为“为什么尾部偏离重要”的故事开场。

**为什么选这个概念**：

案例重点是分布识别。初学者容易只看直方图中心像不像正态，却忽视尾部偏离；但库存、安全库存和金融风险往往正是由尾部决定的。

**寓言故事标题**：量鞋师的最后三双

**寓言故事**：

王城要给一千名守卫做靴子。量鞋师把脚长从小到大排好，再拿出祖传尺板，说：“只要大多数人的脚和尺板差不多，这批靴子就能做。”

前九百多人都很顺利。尺板中段几乎贴合脚长，学徒高兴地说：“这套尺板准极了。”可到了最后三十人，麻烦来了：有几个守卫脚背很高，有几个脚掌特别宽，还有几个常年巡山，脚型远远偏离尺板。学徒不以为然：“才三十个人，不影响大局。”

量鞋师把做好的靴子摆到城门口。大多数守卫确实合脚，但真正要在暴雪夜追马贼的，偏偏是那些脚型极端、巡山最久的人。他们的靴子磨破得最快，行动也最危险。学徒这才明白，中心处贴合不能证明整套尺板可靠；越是在边缘，越能看出尺板是否真的懂这些脚。

故事快结束时，尺板变成了理论分布，守卫脚长变成了样本分位数。我们真正关心的不是直方图中间好不好看，而是样本尾部是否沿着理论线走。这个工具就是 QQ 图；尾部偏离说明候选分布可能低估极端需求或极端风险。

**概念解释**：

- 一句话人话：QQ 图像把样本分位数和理论分位数一一对齐，看数据整条分布，尤其尾部，是否像某个理论分布。
- 严格一点说：QQ 图比较经验分位数与候选分布分位数；若样本来自该分布，点应近似落在一条直线上。
- 容易误解：直方图中心像正态，不代表尾部也像正态；大样本检验显著也不一定表示模型不能用于教学近似。
- 在本课程案例中怎么用：对日需求分别画正态、对数正态、指数 QQ 图，重点观察尾部偏离。
- 现实中什么时候会失效：样本量太小、数据非独立或混合了多个业务机制时，QQ 图可能难以给出明确判断。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 祖传尺板 | 候选理论分布 | 用来解释样本形状 |
| 守卫脚长排序 | 经验分位数 | 从小到大比较位置 |
| 中段贴合 | 分布中心拟合好 | 常见但不充分 |
| 最后三十人的异常脚型 | 尾部偏离 | 极端值暴露模型问题 |
| 暴雪夜追马贼 | 极端风险场景 | 实战中尾部更关键 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：如果直方图中间很像正态，但 QQ 图尾部明显翘起来，你会继续用正态分布估安全库存吗？

分布识别不只是看“多数数据像不像”，还要看尾部是否被低估。库存缺货、金融亏损和服务水平，常常都由尾部决定。
```

**边界与风险提醒**：

这个故事可能让读者以为尾部永远比中心重要。正文应补一句：如果业务只关心平均水平，中心拟合更重要；如果关心风险、缺货、VaR，尾部才是关键。

### 章节：`04-case-clt.md`

#### 概念 1：中心极限定理的适用边界

**建议融入位置**：`### 需要多少个样本？` 之后，强化 “n=30 不是魔法数字”。

**为什么选这个概念**：

CLT 很容易被学生记成“样本量超过 30 就一定正态”。这章的关键不是背公式，而是理解独立同分布、有限方差和原始分布偏态程度对收敛速度的影响。

**寓言故事标题**：三队信使的平均脚步

**寓言故事**：

王城要估计送信到边境的平均时间。书记找来三队信使：第一队走平路，每个人速度差不多；第二队穿市集，有时被人群堵住；第三队翻雪山，偶尔会遇到封路，一耽搁就是好几天。

书记想省事，便说：“每次派三十个人，算平均时间。三十是老规矩，平均数自然会稳定。”第一队果然如此，几次平均都很接近。第二队也还可以，只是偶尔偏一点。到了第三队，平均数却像天气一样乱跳：只要有一个人被雪困住，整队平均就被拖得很长。

书记抱怨规矩不灵。老驿长说：“规矩没有错，是你忘了问路况。平路上的三十人，和雪山上的三十人，不是一回事。若每个人的路都互相牵连，或偶尔出现没有上限的耽搁，平均脚步就不会按你想的速度变稳。”

故事快结束时，我们才意识到这不是驿站管理，而是在讲样本均值为什么有时会变得像钟形曲线，有时不会。中心极限定理很强，但它不是“30 人魔法”。它需要独立、同分布、有限方差；原始分布越偏、尾部越重，需要的样本量就越大。

**概念解释**：

- 一句话人话：CLT 说很多独立小随机因素的平均值会趋近正态，但它有条件，收敛速度也看原始分布有多“怪”。
- 严格一点说：在独立同分布且均值、方差有限的条件下，标准化样本均值随样本量增大收敛到标准正态分布。
- 容易误解：`n=30` 只是经验规则，不是定理保证；重尾、强相关或无限方差会破坏直觉。
- 在本课程案例中怎么用：比较均匀、指数、对数正态等原始分布在不同样本量下的样本均值分布。
- 现实中什么时候会失效：金融极端收益、强自相关时间序列、Cauchy 类无限方差分布都不能简单套用普通 CLT。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 每队信使平均时间 | 样本均值 | 由多个随机个体求平均 |
| 平路信使 | 对称、方差有限的温和分布 | 收敛快 |
| 市集堵路 | 偏态分布 | 需要更大样本 |
| 雪山封路 | 重尾或极端值 | 平均值容易被尾部拖动 |
| 信使互相牵连 | 非独立样本 | 破坏 CLT 条件 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：为什么均匀分布可能 n=5 就很像正态，而严重偏态的对数正态 n=100 还不够？

CLT 很强，但不是“n=30 魔法”。原始分布越偏、尾部越重，样本均值靠近正态所需的样本量就越大。
```

**边界与风险提醒**：

这个故事可能让读者觉得 CLT 很脆弱。正文应补一句：在有限方差且近似独立的许多实际场景中，CLT 仍是非常可靠的近似工具。

### 章节：`05-case-bayesian.md`

#### 概念 1：基率与后验概率

**建议融入位置**：`## 场景` 中 “不是。让我们用贝叶斯定理来算一下。” 之前或之后。

**为什么选这个概念**：

案例的核心反直觉点是 99% 准确率不等于阳性后 99% 患病。这个误解本质上是忽略基率，把 `P(T+|D)` 错读成 `P(D|T+)`。

**寓言故事标题**：红印章的告示

**寓言故事**：

城门口贴出告示：凡携带禁盐的人，九十九次里有九十九次会被红印章查出；没有禁盐的人，九十九次里有九十八九次不会被盖红印。第二天，商人阿梁过城门时，货箱上被盖了红印。

围观的人立刻后退：“红印这么准，他几乎一定有禁盐。”阿梁脸色发白。守门官却没有急着判罪，而是翻开进城名册：每天进城一万人，真正夹带禁盐的通常只有十人。若检查所有人，十个夹带者里约有九到十人会被盖红印；但九千九百九十名普通商人里，即使误盖比例很低，也会冒出一大批红印。

众人这才发现，红印很准，并不等于“看到红印就几乎一定有罪”。在一个本来就极少有人夹带禁盐的城市里，红印队伍中会混入不少无辜者。若阿梁再次被独立检查仍是红印，情况才会大幅改变。

故事快结束时，红印章才露出它的数学身份：它不是在直接告诉我们“有罪的概率”，而是在告诉我们“有罪时被盖红印的概率”。要从红印反推阿梁是否有禁盐，必须把基率也放进来。这就是贝叶斯定理在罕见病检测中的核心。

**概念解释**：

- 一句话人话：看到证据后有多该相信某件事，不能只看证据有多准，还要看这件事原本有多常见。
- 严格一点说：贝叶斯定理用 `P(D|T+) = P(T+|D)P(D)/P(T+)` 把先验基率和证据似然合成后验概率。
- 容易误解：检测准确率、灵敏度或特异度不是阳性后的患病概率。
- 在本课程案例中怎么用：罕见病发病率 0.1% 时，一次阳性后后验约 9%，远低于直觉的 99%。
- 现实中什么时候会失效：如果检测并非独立、基率估计错误或人群不是普通人群，后验计算需要调整。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 禁盐者比例很低 | 先验基率 `P(D)` | 事件原本很罕见 |
| 红印章 | 检测阳性 `T+` | 观察到的证据 |
| 夹带者常被盖红印 | 灵敏度 `P(T+|D)` | 有病时阳性的概率 |
| 普通商人也可能被误盖 | 假阳性 `P(T+|not D)` | 健康者阳性的概率 |
| 从红印反推有罪 | 后验 `P(D|T+)` | 需要贝叶斯更新 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：一个测试“对病人 99% 准”，是否等于你阳性后“99% 患病”？

不等于。前者是 `P(阳性 | 患病)`，后者是 `P(患病 | 阳性)`。方向反过来以后，基率会变得非常重要。
```

**边界与风险提醒**：

这个故事可能让读者以为阳性都不严重。正文应补一句：后验概率低不等于可以忽视风险，医学决策还要考虑疾病后果、复检成本和后续证据。

### 章节：`06-case-hypothesis.md`

#### 概念 1：p 值不是假设为真的概率

**建议融入位置**：`### p 值的正确理解` 之前，作为错误直觉故事。

**为什么选这个概念**：

A/B 测试中最常见的误读是把 `p=0.04` 说成“新算法 96% 有效”。这会直接导致错误上线、提前停止和过度解释。

**寓言故事标题**：空仓库里的脚印

**寓言故事**：

夜里，粮仓门口出现一串脚印。守卫长说：“先按仓库无人偷粮来判断。如果真没有小偷，门口出现这么深、这么新的脚印有多奇怪？”

年轻守卫量了脚印、看了泥水，又查了风向，算出一个很小的数。他立刻宣布：“那就说明有九成多概率抓到小偷了！”守卫长拦住他：“你算的不是小偷存在的概率。你算的是在‘没有小偷’这个说法成立时，看到这串脚印有多罕见。”

他们继续调查，发现附近也可能有搬柴人经过，雨后泥地也会放大脚印深度。脚印很反常，足以让“完全没人经过”的说法变得可疑；但它不能单独告诉你谁来了、为什么来、偷没偷粮。

故事快结束时，这串脚印才变成 A/B 测试中的数据，而“仓库无人偷粮”变成原假设。那个很小的数不是“新方案有效的概率”，而是：如果新旧算法真的没有差异，观察到当前或更极端差异的概率有多小。它就是 p 值。

**概念解释**：

- 一句话人话：p 值衡量的是“如果原假设是真的，现在这份数据有多奇怪”，不是“原假设有多可能是真的”。
- 严格一点说：p 值是在 `H0` 为真时，得到当前统计量或更极端统计量的概率。
- 容易误解：`p=0.04` 不表示新算法有 96% 概率有效，也不表示效果有 96% 的业务价值。
- 在本课程案例中怎么用：CTR 从 5% 到 5.3% 时，需用双比例 z 检验判断该差异在 `H0` 下是否罕见。
- 现实中什么时候会失效：提前停止、多重比较、样本非随机或效应量太小都会让 p 值难以支撑业务结论。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 仓库无人偷粮 | 原假设 `H0` | 默认无效果/无差异 |
| 门口脚印 | 观测数据 | 当前看到的证据 |
| 脚印在无人假设下很罕见 | p 值很小 | 数据与 `H0` 不相容 |
| 年轻守卫说九成多有小偷 | 把 p 值误读为后验概率 | 常见统计误解 |
| 继续调查搬柴人和雨水 | 混杂因素与业务解释 | 显著不等于因果或价值 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：`p=0.04` 到底是在说“新算法有效的概率是 96%”，还是在说“如果新算法无效，现在这份数据有多罕见”？

p 值只回答后一个问题。它能帮你判断数据是否和 `H0` 冲突，但不能直接给出 `P(H1 | 数据)`。
```

**边界与风险提醒**：

这个故事可能让读者觉得 p 值没有用。正文应补一句：p 值仍然是控制第一类错误的有用工具，只是不能被解释成后验概率或业务收益。

### 章节：`07-case-monte-carlo.md`

#### 概念 1：CVaR 与尾部损失

**建议融入位置**：`### CVaR（Conditional VaR，条件风险价值）` 之前。

**为什么选这个概念**：

章节已经强调 VaR 的缺陷。CVaR 是比 VaR 更能表达尾部风险的进阶概念，也能自然连接蒙特卡洛仿真、排序分位数和极端损失。

**寓言故事标题**：堤坝外的五个夜晚

**寓言故事**：

河城每年修堤。管账官拿出记录说：“按过去水位看，九十五个夜晚里，洪水都不会越过这条红线。我们按红线修堤，已经够稳。”

城主听后稍安心，却问：“那剩下五个夜晚呢？”管账官说：“那是少数极端情况，红线只保证大多数时候不越界。”城主便让巡河人把那五个越界夜晚单独拿出来看。结果第一夜只是漫过脚背，第二夜冲坏木门，第三夜淹了粮仓，第四夜卷走桥梁，第五夜几乎冲进内城。

管账官尴尬地说：“红线告诉我们，超过它的机会不大。”巡河人却说：“百姓更想知道，一旦超过，会超过多少。”

故事快结束时，红线才显出自己的名字：它是 VaR，一个分位数门槛。它告诉你大多数情况下损失不会超过哪里，却沉默于越线之后的平均惨烈程度。把越线的那些夜晚拿出来求平均，得到的才是 CVaR。它不只问“最坏的 5% 从哪里开始”，还问“进入最坏的 5% 后，平均会多糟”。

**概念解释**：

- 一句话人话：VaR 画出风险红线，CVaR 追问红线之外平均会亏多惨。
- 严格一点说：在损失分布中，VaR 是给定置信水平的分位数；CVaR 是超过 VaR 条件下的期望损失。
- 容易误解：VaR 不描述尾部内部的损失大小；两个组合 VaR 相同，CVaR 可能差很多。
- 在本课程案例中怎么用：蒙特卡洛生成组合收益分布后，先取 5% 分位数得到 VaR，再对更差的样本求平均得到 CVaR。
- 现实中什么时候会失效：若收益分布假设低估厚尾，VaR 和 CVaR 都会被低估；需要压力测试和历史回测。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 堤坝红线 | VaR 分位数 | 多数情况下不超过的损失门槛 |
| 九十五个安全夜晚 | 置信水平内样本 | VaR 覆盖的主体区域 |
| 五个越界夜晚 | 尾部样本 | 最坏一部分情形 |
| 越界后的平均破坏 | CVaR | 条件尾部期望损失 |
| 只看红线的管账官 | 只报告 VaR 的风险管理 | 忽略尾部严重程度 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：如果两个组合的 95% VaR 都是亏 12 万，但一个在最坏 5% 里平均亏 13 万，另一个平均亏 40 万，它们风险一样吗？

VaR 只告诉你尾部从哪里开始，CVaR 才继续追问：真的掉进尾部以后，平均损失是多少。
```

**边界与风险提醒**：

这个故事可能让读者以为 CVaR 总能解决所有风险问题。正文应补一句：CVaR 仍依赖损失分布和样本质量，错误建模会让 CVaR 也显得过于乐观。

### 章节：`08-capstone.md`

#### 概念 1：蒙特卡洛服务水平估计的抽样误差

**建议融入位置**：`### 问题 5：安全库存与服务水平（使用案例5的蒙特卡洛）` 之前。

**为什么选这个概念**：

毕业项目最终要用仿真评估安全库存和服务水平。学生容易把一次仿真结果当作确定答案，而忽略仿真估计也有误差，且误差受仿真次数和场景假设共同影响。

**寓言故事标题**：守门人和一百阵风

**寓言故事**：

山口有一座粮仓，守门人每天要决定门前放多少沙袋。沙袋太少，暴风会把门撞开；沙袋太多，搬运粮食的人又会被堵住。新来的管事想了个简单办法：明天试一天，如果门没被风撞开，就说明沙袋够了。

第一天风很小，十袋沙袋稳稳当当。管事高兴地说：“以后就放十袋。”守门人却没有照做。他连续记了一百天：有时只有微风，有时半夜突起乱流，有时白天安静，傍晚却像有人推着整座山往前走。

管事不耐烦：“你到底要等到什么时候？”守门人说：“我不是在等一个确定的明天。我是在问：若未来有许多种明天，十袋、十五袋、二十袋分别能挡住多少种？”

他把每天的风当作一次排演，让不同数量的沙袋轮流接受考验。十袋在大多数日子都够，却在几场急风里失守；二十袋几乎稳妥，却让运粮队日日绕路；十五袋偶尔吃紧，但总体代价最低。故事快结束时，这个比例才露出真正含义：它就是库存策略里的服务水平，而反复排演未来的做法，就是蒙特卡洛仿真。只是，排演次数越少，这个比例越容易被偶然风向骗到。

**概念解释**：

- 一句话人话：蒙特卡洛服务水平是在很多个可能未来里，统计某个库存策略不缺货的比例。
- 严格一点说：仿真用随机抽样估计服务水平、平均库存和缺货次数；估计值本身存在抽样误差，通常随仿真次数按约 `1/sqrt(n)` 缩小。
- 容易误解：仿真 10000 天不是预测未来 10000 天，而是在当前随机模型下做 10000 次场景评估。
- 在本课程案例中怎么用：对 `(s, Q)` 策略生成需求和补货时间路径，估计满足 95% 服务水平的最小安全库存。
- 现实中什么时候会失效：如果需求分布、补货时间分布或独立性假设错了，仿真次数再多也只是在错误模型内更精确。

**隐喻映射表**：

| 故事中的隐喻 | 对应概念/模型对象 | 为什么这样对应 |
|--------------|-------------------|----------------|
| 山口粮仓 | 库存系统 | 面临缺货和库存成本取舍 |
| 沙袋数量 | 安全库存水平 `s` | 用来抵御需求和补货不确定性 |
| 一百阵风 | 随机场景/仿真路径 | 每阵风是一种可能未来 |
| 门是否被撞开 | 是否缺货 | 策略是否满足服务要求 |
| 挡住多少种风的比例 | 服务水平 | 不缺货的仿真比例 |
| 排演次数太少会被骗 | 蒙特卡洛抽样误差 | 样本量不足导致估计不稳 |

**可插入 Markdown 片段**：

```markdown
> 停一下，想一想：如果某个安全库存水平在 100 次仿真里达到 95% 服务水平，但在 10000 次仿真里只有 91%，你该相信哪个结果？

蒙特卡洛仿真不是预测唯一未来，而是在构造很多个可能未来，估计一个策略在这些未来中表现合格的比例。仿真次数越少，结果越容易被偶然样本带偏。
```

**边界与风险提醒**：

这个故事可能让读者以为“仿真次数越多就一定越真实”。正文应补一句：更多仿真只能降低抽样误差，不能修复错误的需求分布、补货分布或业务假设。
