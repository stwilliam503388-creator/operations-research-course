# 08 综合项目：营销预算连续优化

## 寓言：炼金师的平滑炉

炼金师要调火候、材料和时间，让合金成色最好。年轻助手每次只改一个旋钮，看到成色提高就继续往同方向调。某些炉子里，这样做很可靠，火候越接近合适，成色越稳定改善；可另一只旧炉暗藏冷热不均，同样的调法有时会落进坏坑。

助手以为是自己手法不稳。老师傅让他先摸清炉子的形状：若炉内变化像光滑碗面，局部改善能指向全局；若炉内有暗坑和断裂，只靠附近信息就可能被困住。优化前先判断结构，比盲目换算法更重要。助手这才明白，连续优化项目不只是求一个数，还要解释问题是否凸、约束是否合理、算法是否可靠。

故事快结束时，炼金炉露出凸与非线性优化综合问题的名字。capstone 要把建模、凸性判断、算法比较和敏感性分析连起来。

> 停一下，想一想：什么时候可以相信局部搜索，什么时候必须怀疑它只找到了附近的好点？

这个故事里，火候材料对应决策变量，成色对应目标函数，光滑炉对应凸结构，暗坑对应非凸陷阱。综合项目的关键是先识别结构，再选择算法，并用敏感性分析和边界检查验证结果。

## 项目目标

你要为三个渠道分配营销预算：搜索广告、社交广告、内容投放。每个渠道都有边际收益递减，预算总额有限，还要避免过度集中。

你的任务是建立一个连续优化模型，比较至少两种算法，并做敏感性分析。

## 建模要求

至少包含：

- 决策变量：三个渠道预算
- 目标函数：最大化总转化收益减去投放成本
- 约束：总预算、单渠道上下限、非负
- 凸性或非凸性判断
- 至少两种算法对比
- 参数敏感性分析
- 现实边界说明

## 推荐模型

使用凹收益函数：

```text
revenue_i(x_i) = a_i log(1 + b_i x_i)
```

最大化凹函数等价于最小化凸函数的相反数：

```text
minimize -Σ_i revenue_i(x_i)
subject to Σ_i x_i ≤ budget
           lower_i ≤ x_i ≤ upper_i
```

## 验收标准

- 输出每个渠道的预算
- 检查总预算约束满足
- 检查目标值优于平均分配 baseline
- 比较 SLSQP 和投影梯度结果
- 做至少 3 个预算水平的敏感性分析
- 说明现实中还需要考虑归因误差、投放延迟和渠道相互影响
